# Address Book Management System in C
Description
A console-based Address Book 
Management System developed 
using C programming. This project 
allows users to manage contact information
and store contact details using file handling.
## Features
-Add Contact
-Search Contact
-Edit Contact
-Delete Contact
-Display Contacts
-Store contact details in a database file
-Search contacts using mobile number and Gmail/email
-Handles invalid inputs
## Technologies Used
-C Programming
-Structures
-Arrays
-Strings
-Functions
-File Handling
## Project Files
- 'main.c' – Main program and menu
- 'addressbook.c' – Address book functions
- 'addressbook.h' – Structure definitions and function declarations
- 'database.csv' – Stores contact information
## How to Run
Compile the program using:
gcc main.c addressbook.c -o addressbook
Run the program using:
./addressbook
## Project Objective
The objective of this project is to develop a 
simple contact management system using C 
programming and to gain practical knowledge of 
structures, functions, arrays, strings, and file handling.
